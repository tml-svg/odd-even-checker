# odd-even-checker

A simple C++ program that determines whether a number entered by the user is odd or even using the modulus operator and conditional statements.

## Concepts Used
- Variables
- Input and Output (cin and cout)
- If-else statements
- Modulus operator (%)

## Example

Input: 8

Output: 8 is an even number.

Input: 7

Output: 7 is an odd number.
